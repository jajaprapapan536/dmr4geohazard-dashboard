# 🌍 ระบบตรวจสอบและบันทึกข้อมูลธรณีพิบัติภัย (Geohazard Inspection Portal)

ระบบบันทึกและแดชบอร์ดติดตามการตรวจสอบธรณีพิบัติภัย พัฒนาขึ้นโดยเฉพาะสำหรับ **นักธรณีวิทยาและทีมงานตรวจสอบภาคสนาม** รองรับการบันทึกเหตุการณ์ เช่น หลุมยุบ ดินถล่ม แผ่นดินไหว รอยแยกผิวดิน และดินทรุดตัว พร้อมการแสดงผลพิกัดภูมิสารสนเทศ (GIS) แบบ Interactive

---

## 🚀 จุดเด่นและฟังก์ชันการทำงาน

### 1. 📝 แบบฟอร์มบันทึกข้อมูลภาคสนาม (Inspection Recording)
* **ข้อมูลวันที่และเหตุการณ์:** วันที่รับแจ้ง, ประเภทพิบัติภัย, ระดับความรุนแรง (ต่ำ, ปานกลาง, สูง, วิกฤต), สถานะการดำเนินงาน
* **ระบบพิกัด UTM:** กรอกค่าพิกัด `UTM_E` และ `UTM_N` ระบบจะแปลงเป็น **Latitude / Longitude (WGS84)** ให้โดยอัตโนมัติ
* **รองรับ 2 โซน UTM ของประเทศไทย:**
  * **Zone 47N (EPSG:32647):** ภาคเหนือ, กลาง, ใต้, ตะวันตก, กทม.
  * **Zone 48N (EPSG:32648):** ภาคอีสาน, ภาคตะวันออก
* **ข้อมูลเชิงพื้นที่:** สถานที่/จุดสังเกต, ตำบล, อำเภอ, จังหวัด (ครบ 77 จังหวัด)
* **ข้อมูลธรณีวิทยา:** กลุ่มหิน/ดิน (Geological Unit), ผู้ตรวจสอบ, รายละเอียดร่องรอยความเสียหายและข้อเสนอแนะ
* **แนบรูปภาพหน้างาน:** อัปโหลดภาพถ่ายสถานที่เกิดเหตุพร้อมคำบรรยายภาพ

### 2. 🗺️ แผนที่พิกัดทางธรณีวิทยา (Interactive GIS Map)
* **แผนที่ภาพถ่ายดาวเทียมความละเอียดสูง (Esri Satellite):** ช่วยให้นักธรณีวิทยาตรวจดูลักษณะภูมิประเทศ ธรณีสัณฐาน และแนวรอยเลื่อนได้ชัดเจน
* **สลับชั้นข้อมูลได้:** Esri World Imagery (Satellite), OpenStreetMap, CartoDB Positron
* **สัญลักษณ์สีตามประเภทภัย:** ดินถล่ม (สีแดง), หลุมยุบ (สีส้ม), แผ่นดินไหว (สีม่วง), ดินทรุด (สีน้ำเงิน) ฯลฯ
* **คลิกดู Popup:** แสดงรหัสเหตุการณ์ พิกัดทั้ง UTM และ Lat/Lon รายละเอียด และภาพถ่ายย่อ

### 3. 📊 แดชบอร์ดวิเคราะห์สถิติ (Analytics Dashboard)
* ตัวเลขสถิติภาพรวม (KPIs)
* กราฟสัดส่วนแยกตามประเภทพิบัติภัย (Donut Chart)
* กราฟจัดอันดับจังหวัดที่พบเหตุการณ์สูงสุด (Top Provinces Bar Chart)
* กราฟแท่งแนวโน้มเหตุการณ์ตามช่วงเวลา/รายเดือน (Timeline Trend)
* ตัวกรองข้อมูลตามประเภทภัย, จังหวัด และสถานะ

### 4. 📋 ตารางข้อมูลและการส่งออก (Export System)
* ตารางสืบค้นและคัดกรองข้อมูล
* ดูรายละเอียดเชิงลึกและภาพถ่ายขยายของแต่ละจุด
* ลบหรือจัดการข้อมูล
* **ปุ่ม Export เป็น Excel (.xlsx):** ส่งออกตารางสรุปรายงานพร้อมหัวคอลัมน์ภาษาไทย
* **ปุ่ม Export เป็น GeoJSON:** นำไฟล์ไปเปิดและวิเคราะห์ต่อบนโปรแกรม **QGIS** หรือ **ArcGIS** ได้ทันที

### 5. 🧭 เครื่องมือแปลงพิกัด UTM (Coordinate Converter)
* แปลงพิกัดกลับไป-มาระหว่าง UTM (Zone 47N / 48N) กับ Latitude / Longitude (องศาทศนิยม)
* มีลิงก์เปิดตำแหน่งใน Google Maps ได้ทันที

## 📂 โครงสร้างโฟลเดอร์ของโปรเจกต์

```
geohazard_dashboard/
│
├── app.py              # แอปพลิเคชันหลัก Streamlit (UI, Map, Dashboard, Forms)
├── coordinates.py      # โมดูลคำนวณและแปลงพิกัด UTM Zone 47N/48N <-> Lat/Lon
├── db.py               # ระบบจัดการฐานข้อมูล SQLite (CRUD, Export GeoJSON)
├── config.py           # ข้อมูลคงที่ (ประเภทพิบัติภัย, จังหวัด 77 จังหวัด, ระดับความรุนแรง)
├── seed_data.py        # ข้อมูลจำลองสถานการณ์ตัวอย่างในประเทศไทย
├── requirements.txt    # รายการแพ็กเกจ Python
├── run.bat             # ไฟล์ดับเบิลคลิกเปิดระบบสำหรับ Windows
├── data/               # โฟลเดอร์เก็บฐานข้อมูล SQLite (geohazard.db)
└── uploads/            # โฟลเดอร์เก็บไฟล์ภาพถ่ายหน้างาน
```
